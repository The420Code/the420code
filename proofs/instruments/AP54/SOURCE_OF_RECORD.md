## The PDF is owed, and the row says so

Every other paper on this wall is served as a PDF at the site root, exported from Word, with its
Contents page numbers read back from Word's own pagination. **No PDF of AP54 was supplied with the
publication pack and none was made here.** Making one would mean re-exporting the paper through some
other tool, which would produce a file the author did not approve, with different pagination and a
digest that matches nothing — and the standing rule for this lock is that a file goes up only as the
exact bytes its digest was taken from.

So AP54's row links the Word file as its text of record, the row's PDF link points at that same file,
and this note records the debt rather than hiding it. **When the PDF is exported from Word it drops
in at `/AP54_Seeing_Alpha.pdf`, the row's links move to it, and the paragraph-level test of record
runs between it and the file above** — which is the check every other of-record paper has passed and
AP54 has not yet been able to.

Until then the Word file *is* the published text, and it is the thing the digest is taken from, so
nothing about the record is uncertain: it is complete and checkable, just not yet in the form the
other fifty-three are served in.
