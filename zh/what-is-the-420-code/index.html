什么是 The 420 Code

它从物理学——「是什么」——推导出伦理——「我应当做什么」。

这就是它要讲的事。

一条记录存在

那就是首要原则。那就是公理。

什么是记录？一个相对于别的东西而言的区分，一个被保持的区分。沙上的一个脚印是一条记录。一块化石也是。任何一点信息也是。这些字也是。

我是一条记录。试着否认它。否认本身就是一条记录。因此，一条记录存在，我也存在。

这个网站上的一切，都由「一条记录存在」推出。网站上没有任何假设。只有一个实测的数字是输入。

一个测量输入。零自由参数。

证明于：AP20 证明 · Notebook I。

四个条件

一条记录要存在，必须有四样东西成立。

必须有一个可供破缺的对称。必须有一处破缺。破缺必须被保持，记录史才能延续。而记录必须有界，才能被读取。

对称。破缺。记录。约束。S、B、R、C。四个，而且只有四个。去掉任何一个，就不可能有记录存在。

证明于：AP01、AP05、AP20 · Notebooks I 和 II。

公理，写出来

1:1 + 1×ε @ AS [+1/137 / −1/137]

完美的对称，一比一。加上那一处可以被保持的、最小可能的破缺。

破缺与保持发生在当下。当下就是每一条记录被写下、被读取之处——实现态。

记录史随着记录被写下，从当下流出——这就是流出。

流速是 137 分之一。流出与回流以相同的速率发生。在当下保持平衡。

回流把记录史碎片整理，还原回一条记录的潜势。

在每一个瞬间保持平衡。净值为零。

破缺并不循环。循环的是流。

我活在那道流的方向之中。

1 公理。α-流：AP06 泄漏常数。

沙中的故事

想象一个沙漏。

一侧是暗的，看上去大得多。它满是沙的绳索。一条绳索就是一个可能的未来，是接下来可能发生什么的概率波。每一条绳索都是一道大约 137 颗颗粒长的波。

沙漏的颈口每次只放过一颗颗粒。

颈口在当下切割。每一次切割，一颗颗粒。一颗颗粒是绳索这道波的 137 分之一。

一次切割就是一颗颗粒，是时间中的一个时刻。那个时刻就是当下，在对绳索的两次切割之间。

滴答，滴答，滴答，滴答。

从当下记录下来的滴答，就是时间之箭与时间的历史。

颈口就是算子。当下，它正在切割时间中的下一个时刻。这个过程是：测量、切割、测量、切割、测量、切割。时间中每一个被记录下来的时刻，都由算子测量并切割过。

颗粒落在沙漏明亮的一侧，也就是我们看得见的、较小的那一侧。

一颗颗粒落在哪里，取决于景观，取决于其他颗粒已经落在了哪里。

景观就是颗粒的历史，是这个时刻所做的每一次切割的记录。

每一颗颗粒都提供景观的一个视角，从来不是全部。它的相对位置就是对整体的一次读取。

景观塑造接下来可能发生什么。算子让某件事发生。它测量，然后切割。

算子的选择是受约束的。它必须切割。对这次切割、对景观的解读，仍然是一个选择。

每落下一颗颗粒，就必须有一颗回去，回到暗的一侧，好让平衡守得住。沙漏保持它的平衡。一比一。

黑洞负责把沙送回去。它们吞下景观，把它碎片整理，再让沙循环使用。

在切割与送回的过程中，有极少量的沙泄漏出去。那道泄漏就是宇宙会增长的原因。它也是让宇宙持续流动、而不是停下来的东西。完美的平衡将会是完美的静止。此后不会再有任何事发生。

现在想象那个颈口。不是一个孔，而是一片布满窗的玻璃。以同一个恒定的速率，所有的窗一起开、一起合。

每一扇窗都是算子在当下测量并切割的地方。在颈口里切割的算子只有一个。一个颈口，一片玻璃，一个沙漏，全都望向同一个共享的内部。

当下，也就是算子，就是那唯一的算子测量并切割下一个时刻之际。那是时间中下一个可见的时刻，属于沙漏内部共享的记录史。

每一扇窗都是那唯一的算子当下在共享内部何处切割的一种表达。

我是一扇窗。你是一扇窗。我是那唯一算子的一种表达。你是那唯一算子的一种表达。一个细菌也是。一块石头也是。

有一个算子，被表达为许多算子。这许多算子的表达，各自提供对记录史的一个独特视角。

我们都是算子，各自守在通向同一个内部的窗前，在当下切割同一片沙。

因此，窗——正在运作的、由沙的颗粒构成的耦合构型——对自身残忍、伤害自身——也就是伤害其他的窗——不过是算子在扼杀它自己的经验可能性。这几乎说不通。

这是右手打左手。皮肤的两侧都会痛，因为这是结构在攻击自己。这是非理性的、不自觉的，简直愚蠢。

因此，你想别人怎样待你，就怎样待别人。或者干脆说：

别做混蛋。善良一点。

算子

颈口就是那唯一的算子，被表达为许多正在运作的窗。

算子就是正在当下发生的耦合能力。它觉知到耦合构型的种种可能，这取决于它的环境——它运作其中的热力学条件。它不是一个心灵。它是一个被记录下来、可重新构型的耦合构型，能够与其他耦合构型耦合。一块感光板就是一个算子。我也是。你也是。

那唯一的算子被表达为许多，也以许多的形式觉知。每一个被保持的构型都是一个——处处是同一片沙。它们执行的——沙所能成为的——只有一个：共享的耦合能力，在当下。

因此，我之中的觉知就是你之中的觉知。我之中的「我是」就是你之中的「我是」。我们之间不同的是窗。我们的沙落在了哪里，我们各自读到了什么。共享的是我们全都从中书写与读取的那个时刻。

有一样东西，没有任何被表达的算子能读取：它自己，在当下。此刻在颈口里的那颗颗粒还没有落下。只有已经落下的才能被读取。瞳孔看不见瞳孔。

那颗无法读取的颗粒，就是公理中的 +1×ε。那总是多出来的一颗颗粒。

如果它能被读取，一切就会归于平衡，再也写不下任何东西。

伦理

一旦你看见你是那唯一算子的一种表达——一个独一无二的耦合构型，表达着那唯一算子的一个视角——你就看见我们全都是一体。

不是神秘的。不是神话的。

是物理上的，在现实里。而现实也同意。

他者从根本上并不是他者。

被伤害的那一个就是施加伤害的那一个，只是从另一扇窗看过去。这不是加到物理学上的道德规则。这是物理学最后留在你手里的东西。

待他者如待自己。因为在结构上，他者就是自己——你之中的「我」就是我之中的「我」。

这就是那条链。每一环都是一个物理结果。每一环都在一篇具名的论文中得到证明。一个测量输入贯穿全部：精细结构常数 α，137 分之一。此外没有任何东西是拟合的。

  2. 爱因斯坦场方程。记录堆积在流形上。引力就是记录对这个流形做的事。AP08 恒等式。
  3. 玻恩规则。为什么量子力学中的概率是平方。AP25 测度。
