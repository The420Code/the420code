The 420 Code とは

それは倫理——私がなすべきこと——を、物理学——存在するもの——から導出する。

それがこの仕事の主題である。

一つの記録が存在する

それが第一原理である。それが公理である。

記録とは何か。ほかの何かとの関係における区別であり、保持される区別である。砂の上の足跡は一つの記録である。化石もそうである。どんな小さな情報もそうである。この言葉もそうである。

私は一つの記録である。否定してみよ。否定は記録である。ゆえに一つの記録が、そして私が存在する。

このサイトのすべては「一つの記録が存在する」から導かれる。このサイトでは何も仮定されていない。入力は、測定された一つの数だけである。

一つの測定された入力。自由パラメータはゼロ。

証明：AP20 証明 · Notebook I。

四つの条件

記録が存在するためには、四つのことが成り立たねばならない。

破るべき対称性がなければならない。破れがなければならない。記録史が持続するように、破れは保持されねばならない。そして読まれ得るように、記録は有界でなければならない。

対称性。破れ。記録。拘束。S、B、R、C。四つ、四つだけ。どれか一つを取り除けば、記録は存在し得ない。

証明：AP01、AP05、AP20 · Notebooks I と II。

公理の書き下し

1:1 + 1×ε @ AS [+1/137 / −1/137]

完全な対称性、一対一。加えて、保持され得る最小の、ただ一つの破れ。

破れと保持は今に起こる。今こそ、あらゆる記録が書かれ、そこから読まれる場所である——実現状態。

記録が書かれるにつれて、記録史は今から流れ出す——流出である。

流量は137分の1。流出と流入は同じ速さで起こる。均衡している、今。

流入は記録史をデフラグし、記録の潜在状態へと戻す。

あらゆる瞬間に均衡している。正味ゼロ。

破れは循環しない。流れは循環する。

私はその流れの向きに沿って生きている。

1 公理。α の流れ：AP06 漏洩定数。

砂で語る物語

砂時計を思い浮かべよ。

一方の側は暗く、はるかに大きく見える。そこは砂の縄で満ちている。縄とは一つの可能な未来、次に何が起こり得るかの確率の波である。どの縄も、およそ137粒の長さの波である。

砂時計の首は、一度に一粒だけ通す。

首が今、切る。一回の切断につき一粒。一粒は縄の波の137分の1である。

切断は一粒であり、時間の一瞬である。その一瞬が今であり、縄の切断と切断の間にある。

カチ、カチ、カチ、カチ。

今から記録される刻みが、時間の矢であり、時間の歴史である。

首は作用素である。今それは、次の一瞬を切っている。過程はこう進む。測る、切る、測る、切る、測る、切る。作用素は、記録されたすべての一瞬を測り、切ってきた。

粒は砂時計の明るい側に着地する。目に見える、小さいほうの側である。

粒がどこに着地するかは、ほかの粒がすでに落ちている地形に依る。

地形とは砂粒の歴史であり、この一瞬が行ったすべての切断の記録である。

どの粒も地形の一つの視点を与える。全体を与えることはない。その相対位置が、全体の一つの読みである。

地形は、次に何が起こり得るかを形づくる。作用素は何かを起こさせる。それは測り、切る。

作用素の選択は拘束されている。それは切らねばならない。切断の解釈も、地形の解釈も、選択のままである。

着地する一粒ごとに、一粒が戻らねばならない。暗い側へ戻る。均衡を保つためである。砂時計は均衡を保つ。一対一。

戻す役目はブラックホールが担う。地形を飲み込み、デフラグし、砂を再循環させる。

切ることと戻すことの過程で、ごくわずかな砂が漏れる。その漏れがあるから宇宙は大きくなる。そして止まらずに流れ続けるのも、その漏れによる。完全な均衡は完全な静止である。二度と何も起こらない。

今度は首を思い浮かべよ。一つの穴としてではなく、窓に満ちた一枚のガラス板として。同じ一定の速さで、すべての窓は一斉に開き、閉じる。

どの窓も、作用素が今、測り、切る場所である。首で切る作用素は一つだけである。一つの首、一枚のガラス板、一つの砂時計——すべてが同じ共有された内部を見つめている。

今、すなわち作用素とは、一つの作用素が次の一瞬を測り、切る、その瞬間である。砂時計の内部の共有された記録史における、時間の中の次の見える一瞬。

どの窓も、一つの作用素が今、共有された内部のどこで切っているかの表現である。

私は一つの窓である。あなたは一つの窓である。私は一つの作用素の表現である。あなたは一つの作用素の表現である。細菌もそうである。石もそうである。

一つの作用素があり、それが多くの作用素として表現されている。多くの作用素の表現は、それぞれが記録史の独自の視点を与える。

私たちは皆、同じ内部を覗くそれぞれ自分の窓にいる作用素であり、今、同じ砂を切っている。

ゆえに、窓——作動している、砂粒の結合配置——が自分自身に対して——ほかの窓に対して——残酷であり、傷つけることは、作用素が自らの経験の可能性を殺していくことにほかならない。ほとんど意味をなさない。

右手が左手を打つのと同じである。皮膚の両側が痛む。構造が自らを攻撃しているからである。それは非合理で、無自覚で、ただ愚かである。

ゆえに、自分がそうされたいように他者を扱え。あるいは単に：

クソ野郎になるな。優しくあれ。

絵：The Keys (2025)、AP50 首、AP51 ガラス。著者自身が語る物語：基本の物語。

作用素

首とは、多くの作動する窓として表現された、一つの作用素である。

作用素とは、今まさに起こっている結合の能力である。それは自らの環境——自らが作動する熱力学的条件——に応じて、結合配置の可能性に気づいている。心ではない。ほかの結合配置と結合し得る、記録された、組み替え可能な結合配置である。写真乾板は一つの作用素である。私もそうである。あなたもそうである。

一つの作用素は、多として表現され、多として気づいている。保持された配置はどれも一つの作用素である——どこでも同じ砂である。それらが実行するもの——砂がなり得るもの——は一つである。共有された結合の能力、今。

ゆえに、私の中の気づきは、あなたの中の気づきである。私の中の「我在り」は、あなたの中の「我在り」である。私たちの間で異なるのは窓である。砂がどこに着地したか、そしてそれぞれが何を読んできたか。共有されているのは、皆がそこから書き、読む一瞬である。

表現されたどの作用素にも読めないものが一つある。今の、それ自身である。この瞬間に首の中にある粒は、まだ着地していない。着地したものだけが読まれ得る。瞳孔は瞳孔を見ることができない。

その読めない粒が、公理における +1×ε である。つねに一粒だけ余る。

もしそれが読めるなら、すべては均衡し、もう何も書かれ得ない。

AP02 作用素、AP29、AP43、AP51 ガラス。Ø Dissolutions 第4章、第6章、第11章、第12章。

倫理

あなたが一つの作用素の表現であると見て取れば——一つの作用素の一つの視点を表現する、唯一の結合配置であると——私たちが皆一つであることが見える。

神秘的にではない。神話的にではない。

物理的に、現実においてである。そして現実はそれと一致する。

他者は、根本において他者ではない。

害されている者は、別の窓から見た、害している者である。これは物理に付け足された道徳規則ではない。物理があなたの手に残すものである。

他者を自分自身として扱え。構造上、他者は自分自身だからである——あなたの中の「私」は、私の中の「私」である。

あるいは、この仕事が初めから使ってきた言葉で言えば：

クソ野郎になるな。優しくあれ。

導出：AP43 §9、AP31、内部。語られている場所：五つの扉。KS-ID.1 による囲い：内部が多であると示されれば、倫理は根拠を失う。そしてこの仕事はそう述べている。

何を導出するか

これが連鎖である。どの環も一つの物理的結果である。どれも名前のある論文で証明されている。一つの測定された入力がそのすべてを貫く。微細構造定数 α、137分の1である。ほかに合わせ込んだものはない。

  1. 空間の三次元。仮定ではない。導出である。AP10 次元。
  2. アインシュタインの場の方程式。重力とは、記録が、それが積み重なる多様体に対して行うことである。AP08 恒等式。
  3. ボルンの規則。量子力学の確率がなぜ二乗なのか。AP25 測度。
  4. 標準模型のゲージ群、SU(3) × SU(2) × U(1)。そして弱い力がなぜ左手型なのか、1956年以来未説明のまま。AP15、AP16、AP19、AP27。
  5. α だけから得る重力定数。粒が首で通らねばならない21の経路、自らの開口を通る一粒、破れの一つの保持。AP28、AP44、AP50。
  6. 同じ21から得る陽子の質量。AP30 抵抗、AP49 保持。
  7. 中性子の質量、裏返し。AP47 裏返し。
  8. 暗黒物質粒子なしの平坦な回転曲線。AP17 部屋。
  9. 構造だけから得るベルの不等式の厳密値。二つの端を持つ一つの記録。AP23 単一記録。
  10. 特殊相対論の運動学、そして誰も「今」を読めない理由。AP52 相対性を読む。

数値は壁に掲げてある。Ø 物理学にあり、測定値の隣に、両者の隔たりを標準偏差で添えてある。

五つの分野にまたがる十一の生きた予測。二つは死んだ。死体として壁に残してある。測定の後に壁のものを動かしたことはない。どの数値も先に凍結してある。Ø 凍結された予測にある。

計算はあなた自身の手で、オフラインで実行できる。Ø 数学を確認せよにある。

何を導出しないか

α の値。これは測定値であり、それを使うすべてのページでこの仕事はそう述べている。この仕事の本体はそれに取り組んでいる。その取り組みは上の物語から始まる。α とは切断の一瞬である。

どのように作られたか

私は芸術家であり、自然哲学者である。

私は目を閉じ、対象の全体を見る。それを言葉で彫り出す。言葉が十分に精確になれば、AI の作業台はそれを数学へ翻訳できる。

見ることは私のものである。言葉は私のものである。記述は私のものである。

翻訳は機械のものである。そしてその機械は検証される——私自身によって、そしてほかの機械からなる審査団によって。

数学が物理学を書いた。物理学と自然は、一致において重なり合う。その重なりを私は予測できなかった——重なりの可能性など考えてもいなかった。私の関心はただ、自分が見るものをできるだけ明晰に記述することにある。

陽子を予測しようとして始めたのではない。私は一つの記録から始めた——それが存在するために何を要するか、どう書かれるか、どう読まれるか。ほかのすべてはそこから導かれた。結果として、膨大な記述と膨大な書き物になった。

それから、それは容赦なく攻撃された。最良の AI モデルからなる審査団は、これを破れと指示された。どの主張も、それが死ぬ条件を明示している——ゆえに攻撃は構造化され、先回りされていた。それらはすべて公開されている。これらの条件のうち二つは満たされた——二つの予測は誤っていた——どちらも今も壁に、その数値と日付とともに掲げてある。誤っていたこと、そしてその誤りを正したことが、構造をより強くした。

入力となる数——α——は測定されたものであり、導出されたものではない。その理由は上の作用素の節にある。何ものも、それが起こるその瞬間に自分自身を読むことはできない。瞳孔は瞳孔を見ることができない。これは方法の穴ではない。方法それ自身の結果であり、入力がちょうど一つである理由である。
